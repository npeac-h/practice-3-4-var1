# Принципиальные архитектурные решения 

1. **Централизация валидации входных данных в методе `isValid`**
   - **Решение:** Все проверки диапазона аргументов (количество, цена, скидка) вынесены в единый метод `isValid()`. Это предотвращает дублирование условных операторов и исключает возможность выполнения расчётов с некорректными данными.

2. **Изоляция бизнес-параметров в статическое поле-константу `VAT_RATE`**
   - **Решение:** Ставка НДС (10% для Варианта 1) зафиксирована в константе `VAT_RATE`. При изменении налогового законодательства или варианта работы требуется модификация только одной константы без изменения алгоритмов в методах вычислений.
